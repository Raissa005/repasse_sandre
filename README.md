# Realize Repasse

### Features

-   PHP 7;
-   ADMLTE2;
-   Composer;

#### Instalando o projeto

Clone o projeto e use o comando `composer i` para instalar as dependências

#### Configurando o projeto

Dentro de `src/config`  copie o arquivo `config.example.php`  e renomeie para `config.php` e configure as variáveis referentes ao seu banco de dados.

Dentro de `db` existe um arquivo para importação da base do banco de dados caso seja necessário.
